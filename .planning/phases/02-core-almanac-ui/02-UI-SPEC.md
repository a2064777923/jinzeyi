# Phase 2 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Typography

Inherited from Phase 1. Phase 2 adds calligraphy display role.

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Body | 16px | 400 | 1.6 | Noto Sans SC/TC | Descriptions, content text |
| Label | 14px | 500 | 1.4 | Noto Sans SC/TC | Section labels, meta text, calendar weekday headers |
| Heading | 20px | 600 | 1.3 | Noto Sans SC/TC | Section headings (h2, h3) |
| Display | 28px | 600 | 1.2 | Noto Sans SC/TC | Page titles (h1) |
| **Calligraphy** | **36px** | **700** | **1.0** | **Noto Sans SC/TC** (bold, tracked) | **Fortune "吉"/"凶" markers on hourly timeline** |
| Calendar lunar | 12px | 400 | 1.2 | Noto Sans SC/TC | Lunar date inside calendar cells |

**Calligraphy note:** The "吉"/"凶" fortune markers use bold weight (700) at 36px with tight letter-spacing (-0.05em) to simulate a brush-stroke aesthetic within the constraints of Noto Sans. If a dedicated calligraphy web font is desired later (e.g., ZCOOL KuaiLe, Ma Shan Zheng), it can be added as a secondary font variable. For Phase 2, bold Noto Sans at large size provides sufficient visual weight.

#### `<HourlyFortuneTable>`

**Props:** `hours: HourlyFortune[]`

**Data type (new):**
```typescript
interface HourlyFortune {
  name: string;          // 子时, 丑时, ...
  ganZhi: string;        // 戊子, 己丑, ...
  star: string;          // 司命, 勾陈, ...
  fortune: '吉' | '凶';  // from ecliptic.getLuck()
  yi: string[];          // recommended activities
  ji: string[];          // activities to avoid
```

**Desktop layout:** Table with columns [时辰, 干支, 吉凶, 星神, 宜, 忌]
**Mobile layout:** Vertical timeline — each row is a card-like block with left-aligned time + fortune marker, right-aligned details.

**Fortune marker rendering:**
- 吉: 36px bold red text `#C43B3B` with gold accent `#B8860B`
- 凶: 36px bold gray text `#6B6B6B`
- Tight letter-spacing: `tracking-tight`

**Props:** `year: number, month: number, days: CalendarDay[]`

**Data type (new):**

```typescript
interface CalendarDay {
  solarDay: number;      // 1-31

  fortune: '吉' | '凶' | '平';  // from ecliptic luck
```

**Navigation:** Left/right arrows to switch months. Month display: "2026年5月 · 農曆四月"

## Interaction Contracts

### Homepage — Today's Almanac Card

- **Load behavior:** Server Component — data fetched at render time via `getDailyAlmanac()`. No loading spinner needed (SSR).
- **Expand/collapse:** Collapsible component. Default state: collapsed. Click "展开更多" to reveal secondary info. Button text toggles to "收起".
- **Animation:** Smooth height transition (200ms ease-in-out) on expand/collapse.
- **Yi/ji badges:** Wrap to multiple lines. Each badge is a pill shape with rounded-full.

### Hourly Fortune Table

- **Desktop (>768px):** Full table layout with all columns visible.
- **Mobile (<=768px):** Vertical card layout — each hour is a stacked block:
  ```
  ┌──────────────────────┐
  │ 子时 (23:00-01:00)   │
  │         吉           │  ← FortuneMarker
  │ 星神：司命           │
  │ 宜：嫁娶, 移徙, ...  │
  │ 忌：出行, 赴任       │
  └──────────────────────┘
  ```
- **Scroll:** On very small screens (<360px), horizontal scroll via ScrollArea for table view.

### Monthly Calendar

- **Month navigation:** Left/right arrow buttons. Clicking updates the URL query param `?month=YYYY-MM` and re-renders (Server Component with searchParams).
- **Day cell click:** Navigates to `/[locale]/almanac/YYYY-MM-DD`.
- **Day cell hover (desktop):** Tooltip shows: solar date, lunar date, fortune, yi/ji summary (top 3 items).
- **Today indicator:** Bold primary border + "今天" label below the cell.
- **Empty cells:** Days outside the month range render as empty (transparent bg, no interaction).
- **First day offset:** CSS Grid with `grid-column-start` calculated from the weekday of the 1st.

### Solar Terms Page

- **Layout:** 4 seasonal groups (春/夏/秋/冬), each as a Card.
- **Each term row:** Term name (large) + date + jie/qi classification + brief description.
- **Data source:** tyme4ts `SolarDay.getTerm()` — iterate through each day of the year, record term transitions.
- **Static content:** Term descriptions and traditional customs are static content defined in i18n message files (not from tyme4ts).

### Daily Almanac Detail Page

- **URL:** `/[locale]/almanac/YYYY-MM-DD`
- **Rendering:** SSR via Server Component. `generateMetadata()` for SEO title/description.
- **Navigation:** "返回月曆" link (back to calendar page, preserving month context). "回到今天" link (navigate to today's detail page).
- **Tabs:** Default tab is "概覽". Tab state is URL-based (`?tab=hours`) for deep linking.
- **Invalid date:** If date is out of range or invalid, show 404 with "找不到该日黄历" message.

### Header Navigation (D-14/D-15)

- **Links added:** 首頁 (/[locale]/), 月曆 (/[locale]/calendar), 節氣 (/[locale]/solar-terms)
- **Active state:** Current page link has primary color text + 2px bottom border in primary.
- **Layout:** Brand (left) → Nav links (center) → Locale toggle (right). On mobile, nav links collapse.
- **Detail page:** Not in nav — accessed via calendar day click (per D-15).

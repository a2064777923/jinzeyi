# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase scope:** Project scaffolding, i18n routing, almanac data service, Redis cache, PostgreSQL, responsive layout, legal disclaimers. This phase establishes the design system foundation that Phases 2-5 build on.

**UI surface area:** Layout shell (header + main + footer), Chinese typography, color tokens, locale toggle, legal disclaimer footer. No content components yet (those are Phase 2).

## Typography

Chinese content is visually denser than Latin text. Base font size is 16px (not 14px) for readability. Traditional Chinese characters need slightly more visual space.

| Role | Size | Weight | Line Height | Font | Usage |
|------|------|--------|-------------|------|-------|
| Body | 16px | 400 (regular) | 1.6 | Noto Sans SC/TC | Paragraph text, descriptions, content |
| Label | 14px | 500 (medium) | 1.4 | Noto Sans SC/TC | Form labels, captions, meta text, footer links |
| Heading | 20px | 600 (semibold) | 1.3 | Noto Sans SC/TC | Section headings (h2, h3) |
| Display | 28px | 600 (semibold) | 1.2 | Noto Sans SC/TC | Page titles (h1), hero text |

**Font loading strategy:**
- Use `next/font/google` to load both `Noto_Sans_SC` and `Noto_Sans_TC`
- Apply via CSS variable `--font-sans` on the `<html>` element
- Switch font-family based on `next-intl` locale in the root layout
- Subset: `chinese-simplified` for SC, `chinese-traditional` for TC (automatic by next/font)

**Content width constraint:**
- `max-w-[65ch]` for prose/content areas (Chinese characters are wider than Latin)
- Full width for layout chrome (header, footer, sidebar in later phases)

## Color

Modern Chinese aesthetic: red/gold for auspicious themes, but clean and contemporary. Not kitsch, not corporate.

### Light theme (default)

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFBF5` (warm off-white) | Page background, main surfaces |
| Secondary (30%) | `#F5F0E8` (light warm gray) | Cards, sidebar, nav background |
| Accent (10%) | `#C43B3B` (modern Chinese red) | See reserved-for list below |
| Gold highlight | `#B8860B` (dark gold) | Auspicious indicators, ratings, emphasis |
| Text primary | `#1A1A1A` (near black) | Body text, headings |
| Text secondary | `#6B6B6B` (medium gray) | Captions, meta, disabled text |
| Border | `#E5DFD5` (warm light border) | Card borders, dividers |
| Destructive | `#DC2626` (standard red) | Destructive actions only |
| Success | `#16A34A` (green) | Auspicious/positive indicators (Phase 2) |

**Accent (#C43B3B) reserved for:**
1. Primary buttons (CTA)
2. Navigation active state indicator
3. Locale toggle active state
4. Footer disclaimer link hover

**Gold (#B8860B) reserved for:**
1. Auspicious day indicators (Phase 2)
2. Fortune rating stars/badges (Phase 2)
3. Brand accent on "擇" character in logo (if applicable)

### Dark theme

Deferred. Phase 1 implements light theme only. Dark theme can be added in a later phase using CSS variables.

## Layout Contract

### Root layout structure

```
<html lang={locale}>
  <body>
    <Header />
    <main className="mx-auto max-w-[65ch] px-4 py-8">
      {children}
    </main>
    <Footer />
  </body>
</html>
```

### Header

- **Height:** 56px mobile / 64px desktop
- **Background:** `#F5F0E8` (secondary surface)
- **Border-bottom:** 1px `#E5DFD5`
- **Content:** Brand name (left), locale toggle (right)
- **Max-width:** Full width, content centered with `max-w-7xl mx-auto px-4`
- **Sticky:** Yes, `sticky top-0 z-50`

### Main content area

- **Max-width:** `max-w-[65ch]` for prose content
- **Padding:** `px-4 py-8` (16px horizontal, 32px vertical on mobile; wider padding on desktop)
- **Centered:** `mx-auto`

### Footer

- **Background:** `#F5F0E8` (secondary surface)
- **Border-top:** 1px `#E5DFD5`
- **Content:** Legal disclaimer (centered, small text), copyright
- **Disclaimer text size:** 12px (`text-xs`), color `#6B6B6B`
- **Padding:** `py-6 px-4`

### Responsive breakpoints

Use Tailwind default breakpoints:
- `sm`: 640px (large phone landscape)
- `md`: 768px (tablet)
- `lg`: 1024px (desktop)
- `xl`: 1280px (wide desktop)

Mobile-first: base styles target 320px+ screens.

## Interaction Contracts (Phase 1)

### Locale toggle

- **Type:** Two-option toggle button (not dropdown)
- **States:** Active locale is visually distinct (accent color underline or filled background)
- **Behavior:** Click switches locale via `next-intl` router; page reloads with new locale prefix
- **URL change:** `/zh-hant/...` <-> `/zh-hans/...`
- **Persistence:** Locale preference stored in cookie (`NEXT_LOCALE`)
- **Accessibility:** `aria-label="切換語言"` / `aria-label="切换语言"`

### Sticky header

- **Behavior:** Header stays at top on scroll
- **Shadow:** Subtle `shadow-sm` appears on scroll (add via scroll event or CSS `position: sticky`)
- **No hide-on-scroll:** Header always visible (simplicity for Phase 1)

### Footer disclaimer

- **Always visible:** Rendered in every page's footer via root layout
- **Not dismissible:** No close/hide mechanism
- **Links:** None in Phase 1 (may add privacy policy link later)

# 今择易 SEO / GEO 增长执行清单

## Phase 1：可发现性与可信结构

- 生产环境统一使用 `https://www.jinzeyi.cn` 作为 canonical、Open Graph、robots、sitemap 与分享链接默认域名。
- 保持 `/sitemap.xml` 与 `/zh-hant/sitemap.xml`、`/zh-hans/sitemap.xml` 可访问，提交到 Google Search Console、Bing Webmaster Tools、百度搜索资源平台、360 站长平台、搜狗资源平台。
- 新增 `/llms.txt` 与 `/ai.txt`，给 AI 爬虫和浏览器代理提供主题地图、核心入口、引用边界和 sitemap 地址。
- 首页输出 `WebSite`、`Organization`、`FAQPage`；工具、生肖、节气入口补 `ItemList` 和 `DefinedTermSet`，让搜索引擎与 AI 摘要更容易抓到站点实体关系。
- 保留所有内容边界说明：黄历、生肖、风水、八字、姓名五行均为传统文化与民俗参考，不包装成确定性建议。

## Phase 2：内容集群

- 生肖：用十二生肖、地支、五行、常见年份、合冲关系和择日入口组成集群。每个生肖页继续承接性格、配对和避冲长尾词。
- 节气：二十四节气保留插画、三候、食俗、农事和黄历读法，弹层文章采用故事感表达，避免机械问答模板。
- 工具：八字排盘、姓名五行、推荐日期都要说明输入资料、推算字段、结果边界和下一步入口，增强“可操作”和“可引用”。
- 内链方向：今日黄历 → 月历 → 吉日场景 → 生肖避冲 → 工具核对 → 知识解释，形成连续路径。

## Phase 3：站外提交与增长动作

- Google：提交 sitemap，检查 Page indexing、Enhancements、Core Web Vitals；重点观察 `/zh-hans`、`/calendar`、`/jieri`、`/zodiac`、`/solar-terms`、`/tools`。
- Bing：提交 sitemap，开启 IndexNow；Bing 也会把数据分发到部分 AI 搜索体验。
- 百度/360/搜狗：提交首页、sitemap、核心栏目 URL；中文站不要只等 Google。
- 内容发布节奏：每周挑 2-3 个高意图主题补深度，例如“2026 结婚吉日怎么选”“属马结婚避开什么日子”“清明节气和黄历怎么一起看”。
- 外链与引用：国学、民俗、传统节日、日历工具、中文独立站目录都适合做自然曝光。链接锚文本使用页面主题，避免堆叠关键词。
- 监控指标：收录 URL 数、核心页点击率、搜索词覆盖、AI 来源流量、工具页表单完成率、分享抽屉点击率。

## 文案禁区

- 避免固定转折模板。
- 避免机械速答标题和生硬口头禅。
- 需要快速解释时，用“简单讲讲”“怎么理解”“怎么放进黄历里看”这类更自然的表达。
